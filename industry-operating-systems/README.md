# Industry Financial Operating Systems

Each system in this directory applies a consistent architecture to a different operating model while preserving the accounting controls unique to that industry.

## Portfolio

- [E-Commerce Financial OS](ecommerce-financial-os/) — four operating profiles covering DTC, marketplace, wholesale, national retail, CPG, and 3PL activity
- [SaaS Financial OS](saas-financial-os/) — four operating profiles covering self-serve subscriptions, B2B contracts, hybrid revenue models, and lean SaaS finance
